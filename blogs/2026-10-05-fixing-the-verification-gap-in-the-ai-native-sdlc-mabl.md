Anthropic published its AI-Native SDLC playbook in August, a blueprint for building software when coding agents write most of the code. It opens with a line I agree with: code is no longer the bottleneck. The playbook structures the software development lifecycle (SDLC) as a loop of six stages: plan, design, build, test, deploy, and maintain.
